# 02 — EQ Frequency Bands (Owsinski)

| Range | Name | Character | Too much |
|-------|------|-----------|----------|
| 16–60 Hz | Sub-Bass | Power, felt more than heard | Muddy |
| 60–250 Hz | Bass | Fundamentals of rhythm section | Boomy |
| 250–2 kHz | Low Mids | Warmth / horn-like | Fatigue, telephone quality |
| 2–4 kHz | High Mids | Speech consonants "m/b/v" | Listener fatigue, lisping vocals |
| 4–6 kHz | Presence | Clarity, definition, closeness | — |
| 6–16 kHz | Brilliance | Air, clarity | Sibilance |

**1-octave shorthand:**
31Hz = Rumble/chest · 63Hz = Bottom · 125Hz = Thump/warmth · 250Hz = Fullness/mud · 500Hz = Honk · 1kHz = Whack · 2kHz = Crunch · 4kHz = Edge · 8kHz = Sibilance/definition · 16kHz = Air

## Golden Rules of EQ

1. Sounds muddy → cut 250Hz
2. Sounds honky → cut 500Hz
3. Cut if trying to make things sound *better*
4. Boost if trying to make things sound *different*
5. You can't boost something that isn't there

## EQ Method — Cut First

- Always try cutting before boosting (cutting adds no phase shift)
- Box/undefined instrument → sweep a deep cut through 400–800Hz to find and remove mud
- Bigness → boost in 40–250Hz range; do it at two frequencies (e.g., 60Hz and 120Hz) rather than large boost at one
- Frequency juggling → don't boost the same freq on multiple instruments; if kick is cut at 500Hz, boost bass at 500Hz

## Instrument Magic Frequencies

| Instrument | Key frequencies |
|------------|----------------|
| Bass Guitar | Bottom 50–80Hz; attack 700Hz; snap 2.5kHz |
| Kick Drum | Bottom 80–100Hz; hollowness 400Hz; point 3–5kHz |
| Snare | Fatness 120–240Hz; boing 900Hz; crispness 5kHz; snap 10kHz |
| Toms | Fullness 240–500Hz; attack 5–7kHz |
| Hi-Hat/Cymbals | Clang 200Hz; sparkle 8–10kHz |
| Electric Guitar | Fullness 240–500Hz; presence 1.5–2.5kHz; reduce 1kHz for 4×12 cab |
| Acoustic Guitar | Fullness 80Hz; body 240Hz; presence 2–5kHz |
| Voice | Fullness 120Hz; boominess 240Hz; presence 5kHz; sibilance 5kHz; air 10–15kHz |
| Strings | Fullness 240Hz; scratchiness 7–10kHz |
| Horns | Fullness 120–240Hz; piercing 5kHz |
| Piano | Fullness 80Hz; presence 2.5–5kHz; honky-tonk 2.5kHz |

## EQ Tips

- Narrow Q when cutting; wide Q when boosting
- Roll off bottom → sound sticks out; roll off top → sound blends in
- Vocals: boost 125–250Hz for chest/fullness; 2–4kHz for consonant presence
- EQ reverb returns: darken to blend in, brighten to stick out; roll off low end on busy parts
