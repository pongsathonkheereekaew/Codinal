## Master brickwall limiter — MEASURED (CLEAN)  [shared ML core]
Per-band dynamics bypassed (Master Gate/Exp/Comp Enable = Off, idx5-7; Limiter Enable On, idx8). Identical to ML1/ML8000:
- **Threshold = drive-into-ceiling**: norm 1.0 = 0 dB, norm 0.3 = **−16.44 dB** (lower = louder).
- **Ceiling 0 dB → true-peak ≤ 0 dBFS** (4× TP −0.01; sine RMS plateau −3.0 dB ✓). TP-clean.
- **Mode (6)**: Clean / Soft / Smart / Dynamic / Loud / Crush. **Threshold/Ceiling/Release/Knee** maps **identical to ML1** — see [ML4000_ML1.md](ML4000_ML1.md) calibration table.
- **Static curve** (thr −16.44, ceiling 0; out RMS dB): −36→−23.2, −30→−15.9, −24→−9.4, −18→−3.7, −15→−3.0, −6→−3.0 (knee ~−18..−15; brickwall 0 dBFS peak). Matches ML1/ML8000 core.
- **Latency = 51 samples** (≈1.06 ms @48k) — exact, REAPER `TrackFX` PDC.

## Per-band compressors — MEASURED (CLEAN)
Soloed each band, band-center tone, gate/exp off, comp on (ratio 2 default, thr norm 0.5), master limiter off. **All 4 bands = independent compressors, near-uniform.** GR at in −6 dBFS (band-center, RMS):

Bands 1–3 uniform; HF band (14 kHz) slightly gentler. Crossovers (xover params) default 100 / 1000 / 10000 Hz.

## Per-band gate + expander — MEASURED (CLEAN, band 2)
Soloed band 2, low staircase −84…−6 dB, **Range set to max** (default Range = 0 → no effect; the trap).
- **Gate**: threshold **−60 dB** (default) — hard gate, full attenuation below (in −72 → silenced; in −60 → −61; in −48 → pass ~unity).
- **Expander**: threshold **−24 dB** — downward expansion below (in −36 → −41 [+5 extra], in −48 → −66 [+18], in −60 → −84). Above −24 → unity. Increasing ratio with depth.
(Gate/exp params per-band identical defaults; band 2 representative.)

## Crossover — MEASURED (CLEAN, ML4)
Band Solo **isolates audio** (unlike ML8000). Impulse-FFT per soloed band → corners ≈ defaults **100 / 1000 / 10000 Hz**; slope ≈ **12–18 dB/oct** (impulse-FFT estimate, moderate — not steep LR4).
