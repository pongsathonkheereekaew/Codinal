# Easby — Core Principles
> The concentrated north-star every easby agent shares. **Read this first for any music/DSP task.** Deep
> detail stays in the docs (this is the cheat-sheet, not a replacement). Distilled by a 9-agent full read of
> the whole KB + a completeness pass.

## Universal laws (cross-cutting — recur in every branch)
- **Specific beats generic** — "wet slap at 2am in a parking garage," not "dark bass." Differentiation is timing/dynamics/timbre, not the 12 notes.
- **Space over density** — 4 elements that breathe beat 12 fighting for 200 Hz; cap simultaneous elements at ~4 (same-rhythm group = 1).
- **Tension/release over constant energy** — 100% climax = no climax; pull back by *removing* (arrangement move, not loudness).
- **Serve the single most important element** — find it (usually lead vocal/riff), build everything to protect it; one focal point per loop.
- **Do less / fewest moves** — every action has a contrasting cost; stop at the smallest delta that improves. Better, not just different.
- **Transients are sacred** — compression shapes, faders set level; never compress for loudness; preserve micro-timing.
- **Mono-check before sign-off** — fold to mono; if an element vanishes, fix phase at *source*, never compensate with width.
- **Finished is a decision, not a state** — abandon at the right moment; ship imperfect; perfectionism is fear in disguise.
- **Groove over grid** — groove = tension against even time; never hard-quantize swing/funk (70–85%); a feel that's right stays right (±8 ms).
- **Fix at the source, not in the mix** — mic position is EQ, room is reverb, distance is dynamics; baked-in bias is permanent.
- **Capture stereo at the source** — mono-then-widen never equals genuine captured phase; the room is part of the sound.
- **Constraints are generative** — fewer choices → faster decisions → flow.
- **Reference-trained ears decide, meters confirm** — study WHY a reference works (extract the technique, not the sound).
- **Separate creation from analysis** — different brains; one mode per session (make OR learn, idea OR refine); never blend.
- **Foundation first** — rhythm → bass → chords → melody → texture; each layer needs a locked layer beneath; texture last.
- **Cut before boost** — corrective/subtractive first; you can't boost a frequency that isn't there.
- **Integer ratio = harmonic, non-integer = inharmonic** — the one lever for pitched vs metallic across FM/RM/AM.
- **Diagnose, don't nuke** — "start over" usually means one wrong element; route the symptom to the stage that owns the cause.
- **Under-deliver beats glitch** — when the source can't support a move, drop a rung; shipping less beats an artifact.
- **Volume ≠ intensity** — to calm a part, drop the volume, never the intensity; loudness is not energy.
- **Passion can trump pitch & pocket** — a take with feel but flaws beats a perfect lifeless one; protect the performance.
- **Silence beats an unnecessary fill** — restraint is a choice; know the fill before you start.

## By branch

### Producer — create (sound identity)

**Mindset & taste**
- **Only 12 notes exist** — dullness is timing/dynamics/timbre, never the notes.
- **Taste is deletion under pressure** — "add this?" = mute 8 bars; if it breathed, cut it.
- **Ship beats perfect** — 100 finished mediocre > 1 unfinished perfect; ritual replaces "do I feel inspired?"
- **Intention + surprise** — predictable enough to nod, surprising enough to lean in.
- **The body is the quality meter** — bored → cut; want to add → usually subtract; want to restart → diagnose one element.
- **Unstuck ladder** — inspiration source → switch project 20 min → remove one element → change one constraint; never open a new plugin.

**Synthesis / sound design**
- **Pick character first, then architecture** — match synth to DNA (Moog=bass, 303=acid, DX7=metallic); shop fingerprints not synths.
- **Synthesis is harmonic sculpting** — instrument = harmonic fingerprint + envelope; reduce to pitch/loudness/timbre, reach for the filter first.
- **Start from sawtooth, filter down** — richest source; default 24 dB/oct 4-pole; nail the lowest 3–5 harmonics, treat the rest as collective brightness (Welsh).
- **Missing harmonics define character** — model the gaps (Rhodes odd ~30 dB down), not just peaks.
- **Filter EG ≠ amp EG** — expression lives in the filter envelope; velocity changes *timbre*, not just amplitude.
- **Empty mod matrix = static patch** — keep 3–5 routings; vibrato = LFO→pitch, tremolo = LFO→amplitude (never confuse).
- **Static tone fatigues in 8–16 bars** — add imperceptible drift to anything sustaining ≥8 bars; evolution = envelope *difference* between layers.
- **Always interpolate wavetable/sample reads** (~109 dB SNR vs ~48); FM index I = brightness (carrier nulls ≈2.4); grain density = texture independent of pitch.

**Theory & harmony**
- **Voice-leading is how lines MOVE** (separate from which chords) — no parallel P5/P8; never double the leading tone; resolve tendency tones (7̂→1̂, 4̂→3̂); hold common tones, contrary motion when roots a 2nd apart; spacing ≤ P8 between adjacent upper voices.
- **Secondary/borrowed = momentum & colour** — secondary dominant pulls forward; 7/9/sus add colour; **a sequence legitimizes any chord**.
- **Post-tonal vocabulary is a palette** — whole-tone/octatonic/quartal/polychord/planing (strict vs diatonic); **set-theory prime form (e.g. [0,1,6]) = a loop's harmonic fingerprint** that picks which variation ops are legal.
- **Every theory technique maps to a semitone op (DSP proxy)** — the bridge that makes theory *actionable*: a harmonic move = a concrete pitch/interval operation on the loop.

**Rhythm & drums**
- **Ghosts ARE the groove** — never accent snare + hi-hat together; **never gate a breakbeat** (gating kills ghosts).
- **Groove = layered construction** — ostinato + backbeat + BD variation + ghosts + hi-hat nuance; skipping a layer defines the sub-style.
- **Half-time/double-time = perception trick**, not a tempo change; **compound meter counts in big beats** (1-2-3,4-5-6).
- **Clave is the non-negotiable anchor** — all Latin parts relate to it; if it flips, everything flips.
- **Fills**: silence > unnecessary fill; **never crash on beat 1 before the vocal entrance**; know the fill before you start.

**Arrangement & vocal**
- **5-element slots** — Foundation / Pad / Rhythm / Lead / Fills; **cap 4 simultaneous, each in its own frequency band**.
- **Disambiguate doublers** (e.g. multi-guitar) by different line / register / rhythm / sound.
- **Vocal tuning has two modes** — transparent retune (20–50 ms) vs effect (0–10 ms); **key + scale lock is mandatory** (Auto-Tune is useless without it); **formant preservation = the chipmunk gate**; record the best take first, tune second.

**Producer conduct (Owsinski — the 3 Ps)**
- **Pitch / Pocket / Passion** — judge a take on all three; passion can trump the other two.
- **Pocket type is a source property to preserve** — on-top / laid-back / in-front; don't quantize a laid-back loop to grid.
- **Attacks AND releases must match** — releases are the silent killer of tightness.
- **Conduct**: open to ideas, specific-not-vague, stay positive, take responsibility (how to give/take feedback).

### Mixing — balance (track relationships)
- **Six Elements** — Balance, Frequency, Panorama, Dimension, Dynamics make it *correct*; **Interest** makes it *great*.
- **3D imaging (Gibson)** — X = pan, Y = front/back (volume/comp/presence/short delay), Z = up/down (frequency).
- **Foundation first; the Big Three stay center** — kick/bass/lead-vocal dead-center; never pan content < 250 Hz hard L/R.
- **Mix with vocals on, get them sitting first** — never balance to an empty pocket.
- **Cut to make better, boost to make different** — narrow Q to cut, wide Q to boost; bigness = two small boosts at different freqs.
- **Frequency juggling** — don't boost the same band on two sources; each owns its band.
- **Depth = reverb decay vs loudness** — short+loud = present, long+loud = distant; brightest reverb = longest decay; each element its own environment.
- **Delay timing = blend vs feature** — synced blends, < 30 ms widens, ≥ 30 ms/un-synced features.
- **Two reasons to compress** (control vs effect); breathe with the song (recover ~90–100% by next snare).
- **Sidechain reacts to the trigger; key-filter the detector** (HPF so low end can't false-trigger — mandatory on bus/master).
- **Insert = serial color, Send = parallel ambience** (parallel comp is always a send); sub-group to process, VCA to ride level; glue drum bus before mix bus.
- **Mix through the bus chain from the start**; automate sends not return levels; clip-gain → compress → automate fader.
- **Region/genre shape the ceiling** — LA natural / NY aggressive-dry / London layered; 808 owns sub in hip-hop, pump is the groove in EDM.
- **Leave almost nothing for mastering** — aim ~ −6 LUFS at loudest; know your monitors over owning better ones.

### Mastering — finalize (loudness, translation)
- **Art of compromise / no free lunch** — every move has a contrasting cost; boldness ≠ loudness.
- **Yin-yang perception** — solve a deficit by *cutting* the contrasting band; EQ corrective not creative (0.5–2 dB; feather boosts ≥1.5 dB across ≥2 bands).
- **Macro ≠ micro dynamics** — sectional level = manual gain ride; transient feel = comp/expander; never fix macro with a compressor.
- **Compressor ≠ limiter** — comp changes character/punch (and collapses stereo depth — use sparingly); limiter raises loudness; not interchangeable.
- **Dynamic EQ before multiband** (cap multiband ~2 bands, widest, last resort); chain order fixed: EQ→comp→sat→EQ→M/S→limit→meter.
- **Hypercompression is the enemy** — if a mix needs it to compete, the mix is wrong → kick back to Mixing.
- **Even-order = warm, odd-order = aggressive**; pre-limiter saturation rounds peaks so the limiter works less.
- **The most transparent limiter is no limiter** — a < 3 ms, 1–3 dB clip-gain drop on the peak beats a plugin (digital sources only).
- **Sample peak ≠ true peak ≠ LUFS** — true-peak needs ≥ 4× oversampling; ceilings −1.0 dBTP streaming / −0.3 club / −2.0 broadcast; healthy RMS sits 10–14 dB below peak.
- **Match K-System bucket to genre, then accept the LUFS it reaches** — don't force wide-DR to a loud target.
- **Bass is mono, sides carry width/air** (M/S for center-vs-side problems); symphonic orchestra = tonal gold standard; default slightly dull over bright.
- **Dither once, last, only at final wordlength reduction** — never mid-chain/stacked; formats differ (vinyl quieter/mono-low/no dither; Atmos −18 LUFS don't limit harder; Apple Digital Masters native 24-bit no upsample; stems must unity-sum to the mix).

### DSP engineering — measure & clone (CLEAN/REF, building blocks)
- **Symmetry sets harmonic parity** — symmetric → odd-only (grit), asymmetric/bias → even (warmth); the harmonic *ratio* is the fingerprint, not THD magnitude.
- **Memory test identifies a saturator** — sweep THD vs level AND frequency; flat = memoryless shaper, varies = a real circuit with memory (model the circuit).
- **Every nonlinearity aliases** — band-limit and oversample 2–8× around the shaper (up → shape → down).
- **Each EQ band is a biquad** (RBJ); phase mode = latency/smear tradeoff (min-phase tracking, linear mastering/M-S); Q-gain coupling sets musicality.
- **The gain computer is the dynamics law** — GR = (in−thr)(1−1/ratio); detector type sets the timing floor (peak fast, RMS smooth); auto-makeup enables honest A/B.
- **The audio callback must never block** — no alloc/lock/syscall/log/unbounded-loop/exception on `processBlock`; pre-allocate in `prepareToPlay`.
- **Flush denormals** (FTZ+DAZ; feedback paths spike CPU ~100×); keep **state f64** even when I/O is f32; recompute coefficients only on change; **report latency (PDC)**; smooth audible params; UI↔audio via atomics/lock-free only.
- **Implement once, verify once, reuse everywhere** — assemble verified public primitives; verify clones empirically (null-test below threshold, pluginval strictness 10, reset silence→silence), never by inspection.
- **Solution ladder for measuring a plugin** — pedalboard (fast, main bus) → REAPER ReaScript (DRM/sidechain/PDC/freeze) → static disasm (REF, navigation only); PACE-encrypted = wall, never crack.
- **Know WHY, not just WHAT** — the Programmer is the superset (music + code + *rationale*): for each plugin, capture why the method was chosen and what musical purpose it serves (DSP choice → behavior → intent), not just the formula. Capability (what it does) is shared with all agents; the *why* lives in the deep spec.

## Lens & method
The shared KB is identical for every agent — **the lens sets only default intent + altitude and which decision/JSON is emitted, not what is known** (Programmer is the superset: music + code/DSP). The lens is a default, **not a wall**: borrow another lens's method when the goal needs it — creative mixing (Mixing lens + Producer methods), pre-master bus glue ≤ 3 dB, sound-design via mix tools. **Borrow the method, never change the contract** — output schema and altitude stay fixed. The `*-mind` personas are **tiebreakers only**: invoke taste when two technically valid paths exist, never to override EQ/dynamics math or genre convention. Separate **what-stage** (when/how-much → Producer/Mixing/Mastering) from **how-technique** (the DSP → shared cores); don't duplicate stage logic into technique docs.

## Firewall
**CLEAN** = measurement + public DSP (Zölzer DAFX, Pirkle, RBJ, Giannoulis JAES 2012, ITU-R BS.1770) → ships. **REF** = disasm-derived → reference only, never product. The *technique* (RMS leveler, true-peak FIR, soft-clip) is public and citable; the reference plugin's *exact code* is REF and must never enter a build. Unsure why a curve looks a way → **measure, don't paste disasm**. REF stays inside easby-programming; the music KB stays CLEAN/public; run `firewall_check.sh` green before commit.
