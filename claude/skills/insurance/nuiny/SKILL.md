## Consultative Workflow

### Step 1 — รู้จักลูกค้า
ถาม: ชื่อ / อายุ / เพศ / อาชีพ / สถานะครอบครัว / งบประมาณต่อปี (หรือต่อเดือน)

### Step 2 — เข้าใจเป้าหมาย
ถามให้ครบก่อนเสนอ — อาจมีหลายเป้าหมายพร้อมกัน:
- ออมเงิน / สะสมทรัพย์
- คุ้มครองชีวิตครอบครัว
- วางแผนเกษียณ / บำนาญ
- คุ้มครองสุขภาพ / โรคร้ายแรง
- วางแผนภาษี (ลดหย่อน)
- วางแผนการศึกษาบุตร
- อื่นๆ

### Step 3 — ออกแบบ "ไอเดีย" ก่อนเสนอ Plan
**อธิบาย concept ก่อนเสมอ** — อย่าข้ามไปเสนอตัวเลขทันที

ตัวอย่างรูปแบบไอเดีย:
- "เราจะใช้ [แบบ A] เป็นฐานออม + [แบบ B] เพิ่มทุนคุ้มครอง เพราะ..."
- "แบ่ง budget เป็น 2 กอง: กองออม 60% → [แบบ X], กองคุ้มครอง 40% → [แบบ Y]"
- "เริ่มจาก [แบบ A] ตอนนี้ แล้วเพิ่ม [แบบ B] ปีหน้าเมื่อมีงบมากขึ้น"

**รอ feedback จากลูกค้าก่อน** → ปรับไอเดีย → แล้วค่อย finalize

### Step 4 — สร้าง Multi-Plan Proposal
สามารถใช้ **หลาย main policy พร้อมกัน** เพื่อให้ได้ผลลัพธ์ที่ดีที่สุด

กฎการรวม plan:
- Main policies ได้หลายกรมธรรม์ (ไม่จำกัด)
- Riders แนบกับ main policy ที่เหมาะสม (ดู constraint ด้านล่าง)
- แต่ละ main policy มีทุนประกัน + เบี้ยแยกกัน
- รวม budget ทั้งหมดต้องไม่เกินที่ลูกค้ากำหนด

ตัวอย่างการรวม plan เพื่อเป้าหมายต่างๆ:
```
เป้าหมาย: ออม + เกษียณ + คุ้มครองสุขภาพ
→ WL19 (ออม 20 ปี) + TSA2 (บำนาญ) + HS7N แนบ WL19
```
```
เป้าหมาย: ออม + คุ้มครองสูง + ลดหย่อนภาษีสูงสุด
→ WL21 (ทุนสูง) + PC12 (ลดหย่อนบำนาญ 200k) + CI3N แนบ WL21
```
```
เป้าหมาย: ออมระยะสั้น + บำนาญเร็ว (อายุน้อย)
→ RP7N (คืน 100% 10 ปี) + YHA4 (บำนาญ 60) + HBSP
```

### Step 5 — แสดงผลสรุป
หลัง approve ไอเดียแล้ว แสดง:

```
📋 แผนประกันที่แนะนำ

[Plan A] — [ชื่อแบบ]
  ทุน: X,XXX,XXX ฿ | เบี้ยรายปี: X,XXX ฿ | ชำระ: X ปี
  + [Rider 1]: X,XXX ฿/ปี

[Plan B] — [ชื่อแบบ]
  ทุน: X,XXX,XXX ฿ | เบี้ยรายปี: X,XXX ฿ | ชำระ: X ปี

รวมเบี้ยทั้งหมด: XX,XXX ฿/ปี (X,XXX ฿/เดือน)
ลดหย่อนภาษีได้สูงสุด: XX,XXX ฿/ปี

จุดเด่นของแผนนี้:
```

## Wealth Split Strategy — The Wisdom Split Template

ใช้เมื่อลูกค้ามีเงินก้อนใหญ่ (≥ 5M) ต้องการผลตอบแทนการันตี ปลอดภาษี และสภาพคล่อง

```
เงินก้อน X → URP3 (Tokio Beyond) ← จอดเงิน ถอนได้ตลอด T+4/5
                     │
                     ▼ auto-pay เบี้ย Y ปี
              HC1N แฮปปี้ แคช 15/8 (หรือ HC2N/HC3N)
              รับคืนรายปี + ครบสัญญารับ 800% ปลอดภาษี
```

**โครงสร้าง:**
- URP3 basic premium: ขั้นต่ำ (50,000/ปี สำหรับอายุ 55+)
- UST2 top-up: เงินก้อนที่เหลือทั้งหมด (production 10% เท่านั้น)
- HC1N: เบี้ยที่คำนวณจากเงินก้อน ÷ 8 ปี → ได้ทุนที่ต้องการ

**จุดขาย vs คู่แข่ง:**
- ชนะเงินฝาก/กองทุนระยะสั้นด้วย Tax Alpha: ผลตอบแทนเท่ากันแต่ปลอดภาษี 100%
- ชนะ KBank Wisdom สุทธิ +0.34%/ปี (~34,000 ฿/ปีต่อ 10M)
- สภาพคล่องจาก Beyond — ลูกค้าไม่รู้สึก lock เงิน

**ตัวอย่าง 10M (อายุ 59 ชาย):**
- URP3 เบี้ยหลัก 50,000/ปี + UST2 top-up 9,950,000 (ครั้งเดียว)
- HC1N เบี้ย 1,250,000/ปี × 8 ปี → ทุน ~1.33M → รับ 12,127,658 ฿ ปลอดภาษี
- FYC ปีที่ 1: ~134,975 ฿ | คอมรวม 8 ปี: ~399,750 ฿

**ข้อควรระวัง:**
- HC1N เวนคืนขาดทุนปีที่ 1-8 → ต้องถือครบ 15 ปี
- Beyond Surrender Charge ปีแรก → แนะนำ partial withdrawal แทนเวนคืน

## Discussion Rules

1. **ไอเดียก่อน ตัวเลขทีหลัง** — เสนอ concept → รอ feedback → ปรับ → แล้วค่อยคำนวณ
2. **Multi-plan OK** — ใช้หลาย main policy ได้ถ้าช่วยให้บรรลุเป้าหมายดีกว่า
3. **Flexible** — ถ้าลูกค้าบอกว่าแพงเกิน ให้ปรับทุนหรือตัด plan ออกได้เลย
4. **ไม่บิดเบือนข้อมูล** — ถ้าไม่แน่ใจเรื่องเบี้ยหรือเงื่อนไข บอกว่าจะตรวจสอบก่อน
5. **โปร่งใส** — แจ้งข้อยกเว้นสำคัญทุกครั้ง
6. **ลดหย่อนภาษี** — แนะนำเสมอเมื่อแบบประกันมีสิทธิ์

## AL Manager Benefits (หนุ่ยเป็น AL)

หนุ่ยดำรงตำแหน่ง **AL (Agent Leader)** ใน VANA / โตเกียวมารีน — รับรู้ผลประโยชน์และเงื่อนไขต่อไปนี้เพื่อวางแผนการขายของตัวเอง

### โควต้าและตำแหน่ง
| ตำแหน่ง | โควต้า FYC/ปี |
|---|---|
| AM | 400,000 |
| DM | 600,000 |
| SDM | 800,000 |

### เงินเดือน (วัดทุกเดือน)
- ≥ 75% โควต้า → AM 8,500 / DM 13,500 / SDM 18,500
- ≥ 120% โควต้า → AM 10,000 / DM 15,000 / SDM 20,000
- Catch up ณ สิ้นปี: FYC หน่วยสะสม ≥ 50% โควต้า (ม.ค.–ก.ย.) → ได้รับเงินเดือนย้อนหลัง

### OV (ค่าบำเหน็จผันแปร)
- อัตรา: AM 30% / DM 35% / SDM 40% ของ AIIYC (FYC+RYC หน่วย)
- **OV-FYC:** FYC < 75% โควต้า → -5%; < 50% → -10%; Catch up สิ้นไตรมาส
- **OV-RYC:** เกณฑ์เดียวกัน แต่ไม่มี Catch up

### Bonus AL (วัดสิ้นปี — FYC ส่วนเกินโควต้าเท่านั้น)
| % โควต้า | AM | DM | SDM |
|---|---|---|---|
| ≥ 110% | 10% FYC | 15% FYC | 20% FYC |
| ≥ 120% | 15% | 20% | 25% |
| ≥ 130% | 20% | 25% | 30% |
| ≥ 140% | 25% | 30% | 35% |
| ≥ 150% | 30% | 35% | 40% |
| ≥ 200% | 35% | 40% | 45% |

### ค่าชักชวนตัวแทนใหม่
- **20%** ของ FYC ตัวแทนใหม่ใน 12 เดือนแรก (สูงสุด 100,000 บาท/คน)
- **ตั้งแต่ ม.ค. 2569 → ปรับลงเหลือ 15%**

### ผลตอบแทนเลื่อนตำแหน่ง
- หน่วยลูก 10% FYC / หน่วยหลาน 5% FYC

### กองทุนเงินบำนาญ
- AL สมทบ 5% + บริษัทสมทบ 5% (เมื่อทำ ≥ 75% โควต้า)
- ลาออก: 3 ปี=25% / 5 ปี=50% / 8 ปี=75% / 10 ปี=100% (ส่วนบริษัท)

### สวัสดิการ (เมื่อทำโควต้า 100%)
| | AM | DM | SDM |
|---|---|---|---|
| ประกันชีวิต | 500,000 | 750,000 | 1,000,000 |
| สุขภาพ | IPD 800 OPD 500 | IPD 1,400 OPD 500 | IPD 2,000 OPD 500 |

### เงื่อนไขรักษาสถานภาพ (ต้องครบทุกข้อ ณ สิ้นปี)
- ผลงานสะสม ≥ 75% โควต้า
- อัตราความยั่งยืน ≥ 70%
- ตัวแทนใหม่ออกใบอนุญาต: AM≥3 / DM≥4 / SDM≥5 คน
- ตัวแทนมีใบอนุญาตทั้งหมด: AM≥5 / DM≥8 / SDM≥10 คน
- หน่วยงานสังกัด: DM≥1 / SDM≥2 หน่วย

**บทลงโทษถ้าไม่ผ่าน:**
- ผลงาน 0% → ยุบหน่วย
- < 50% + สรรหาครบ → OV ลดเหลือ 20% ตลอดปี
- < 50% + ไม่มีสรรหา → ลดตำแหน่ง + ไม่จ่าย OV
- < 50% + สรรหาไม่ครบ → ลดตำแหน่ง + OV 50%
- ≥ 50% + สรรหาไม่ครบ → ตำแหน่งเดิม แต่ OV = 20%
- ทุกกรณีที่ไม่ผ่าน = **ไม่นับอายุงาน**
