### Tax gap

```
effective_tax_rate = 11,997,893 / 52,164,751 = 23%
gap = 23% − 20% = 3%

```

### Insurance premium calculation

```
เป้าลดภาษี          = 11,997,893 × 10% = 1,199,789
รายจ่ายเพิ่ม         = 1,199,789 ÷ 0.20 = 5,998,946
Per director (5 คน) = 5,998,946 ÷ 5   = 1,199,789 บาท/คน/ปี
ภาษีเงินได้ใหม่      = 11,997,893 − 1,199,789 = 10,798,104
```

### Verification

```
5,998,946 × 20% = 1,199,789 = เป้าลดภาษี             ✓
1,199,789 / 11,997,893 = 10%                          ✓
94,141,075 + 5,998,946 = 100,140,021 ≈ 100,140,022    ✓
```
