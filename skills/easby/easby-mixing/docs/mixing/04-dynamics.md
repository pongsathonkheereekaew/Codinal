# 04 — Dynamics: Compression, Gating (Owsinski)

## Two Reasons to Compress

1. **Control dynamics** — keep level consistent (bass notes even, vocal every word audible)
2. **As an effect** — change the volume envelope for aggression, punch, fatness

## Setting the Compressor (Snare-Based Method)

1. Start slowest attack / fastest release
2. Increase attack until instrument begins to dull → stop
3. Set release so level recovers 90–100% by next snare beat
4. Goal: compressor "breathes" in time with the song

## General Compression Starting Points

- Controlling dynamics: 2–4dB GR at 2:1–4:1
- Bass guitar: infinity:1, threshold for 3–4dB GR (solid, unmoving)
- Lead vocal: 4:1, medium attack/release, 4–6dB GR
- Electric guitar: 8:1–10:1 for effect; attack/release timed to pulse
- Kick/snare: avoid crushing — darkens sound; use for consistency not effect

## NY Compression Trick (Parallel Drums)

1. Bus drums (+ maybe bass) to stereo compressor
2. Hit hard: 10dB+ GR
3. Add 6–10dB boost at 10kHz and 100Hz to the compressed signal
4. Blend underneath the dry mix until just audible

→ Rhythm section sounds bigger + controlled without sounding over-compressed

## Buss Compression

- 2–3dB GR only; the compressor adds an intangible sonic quality
- Mix *through* the chain from start — never add buss compression at the end
- Full-range AND multiband processes can be used simultaneously

## Gating

- Gate range 10–20dB on drums lets natural ambience breathe (don't close fully)
- Gate snare effects send so reverb only triggers on forceful hits
