## Master brickwall limiter — MEASURED (CLEAN)  [shared ML core]
Multiband bypassed (idx11=Off), master limiter only (idx5=On). Near-identical to ML1/ML4 → **one shared limiter engine.**
- **Threshold = drive-into-ceiling** (Waves-L style maximizer, *not* downward thresh): norm 1.0 = 0 dB, norm 0.3 = **−16.44 dB**. Lower threshold → more gain/loudness.
- **Ceiling** = peak output ceiling; at 0 dB → holds **true-peak ≤ 0 dBFS** (4× TP = −0.01; sine RMS plateau −3.03 dB ✓). TP-clean.
- **Release**: norm 0 = **1 ms** … norm 1.0 = **5000 ms**.
- **Mode (6)**: Clean / Soft / Smart / Dynamic / Loud / Crush.
- **Threshold/Ceiling/Release/Knee** norm→real maps **identical to ML1** — see [ML4000_ML1.md](ML4000_ML1.md) calibration table (Threshold/Ceiling −36…0 dB log; Release 1 ms–5 s exp; Knee 0–100).
- **Static curve** (thr −16.44, ceiling 0, RMS dB): below ~−18 dB in → linear with ≈+14 dB drive; knee ~−18..−15; brickwall plateau at 0 dBFS peak.
  | in dB | −36 | −30 | −24 | −18 | −15 | −12 | −6 |
  |---|---|---|---|---|---|---|---|
  | out dB(RMS) | −23.5 | −15.7 | −9.1 | −3.6 | −3.0 | −3.0 | −3.0 |
- **Latency = 51 samples** (≈1.06 ms @48k) — exact, REAPER `TrackFX` PDC.

## Per-band limiters — MEASURED (CLEAN)
Soloed each band, band-center tone, threshold norm 0.3 (−16.44 dB), master limiter off. **All 8 bands = independent threshold-driven limiters, near-uniform.** GR at +10 dB over threshold (band-center, RMS):
| band | 1(sub) | 2 | 3 | 4 | 5 | 6 | 7 | 8(hi) |
|---|---|---|---|---|---|---|---|---|
| center Hz | 25 | 63 | 158 | 400 | 1012 | 2530 | 6325 | 14000 |
| GR dB | −10.7 | −13.4 | −13.9 | −14.1 | −14.5 | −14.6 | −14.5 | −13.9 |
Below threshold (in −30) → ~unity. Bands 2–8 uniform (≈−14 dB); sub-band (25 Hz) gentler. Same threshold/release/mode core as the master limiter, per band.

## Crossover + deferred
Crossover **frequencies** known (params, defaults 40/100/250/640/1600/4000/10000 Hz). **Slopes not extractable via solo** — ML8000 `Solo` is **metering-only, not audio-isolating** (impulse through a soloed band returns full-range, flat). To get slopes: drive one band into hard limiting + feed wideband → measure the per-band GR notch vs frequency (deferred). Also deferred: Band Mode/Focus/Snap, HPF/LPF curves.
