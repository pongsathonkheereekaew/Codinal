# 03d — Genre Arrangement Templates

> Originally part of `03-composition-methods.md`. Split for load efficiency. Owns the concrete genre blueprints (Pop, EDM/House, Hip-Hop, etc.) with BPM range, section bar counts, and structural conventions per genre.

## Genre Arrangement Templates

> These are starting blueprints. Genre = audience expectation = a contract the producer can choose to honour or break.

### Pop (3:30–4:00, 100–130 BPM)

```
Intro (4–8 bars) → Verse 1 (8–16) → Pre-Chorus (4–8) → Chorus (8–16) →
Verse 2 (8–16) → Pre-Chorus (4–8) → Chorus (8–16) →
Bridge (8) → Chorus ×2 (16–32) → Outro (4–8)
```

- **Density rule**: verse < pre-chorus < chorus. Each transition adds layers.
- **Pre-chorus is the lift**: typically uses subdominant (IV) or vi to telegraph the chorus.
- **Final double chorus** = the production money shot. Pile on ad-libs, octave-up vocals, key change (optional but classic).

### Hip-Hop / Rap (2:30–3:30, 70–100 BPM)

```
Intro (4–8) → Hook (4–8) → Verse 1 (16) → Hook (4–8) →
Verse 2 (16) → Hook (4–8) → Verse 3 (8–16) → Hook (4–8) → Outro (4)
```

- **Modern punchline rap**: 8-bar verse / 4-bar hook. Tighter, more hooks per minute.
- **Beat structure**: loop + drums + 808; layered with melody, atmosphere pad, ad-libs.
- **Hook density > verse density**: drop a percussion layer during verses to leave room for the rap; reintroduce it on the hook.
- **Intro is often hook-first** (hook → verse → hook) to grab attention immediately.

### EDM / House / Techno (5:00–7:00, 120–135 BPM)

```
Intro (16–32) → Break 1 (16) → Build 1 (8) → Drop 1 (16–32) →
Break 2 (16) → Build 2 (8) → Drop 2 (16–32) → Outro (16–32)
```

- **Build mechanic**: add 1 element per bar; filter sweep up; snare roll subdivides (8th → 16th → 32nd); reverse impact + noise riser land on the last bar.
- **Drop**: kick back in HARD; all elements; the loudest moment of the track.
- **Breakdown**: kick OUT, often only pad + lead + atmosphere; vocal chops feature here.
- **Trap/dubstep variant**: 16-bar intro, 8-bar breakdown, 8-bar build, drop at bar 32.

### Jazz Standard (head-solos-head, 3:00–6:00, free tempo)

```
Head (1 chorus AABA or 12-bar blues) →
Solo 1 (N choruses, same form) →
Solo 2 (N choruses) →
… →
Head out (1 chorus) → Tag / coda
```

- **Form is the changes**, not the section names. Solos run over the same harmony as the head.
- **AABA**: 4 × 8 = 32-bar chorus, repeated for each soloist.
- **12-bar blues**: 3 × 4 = 12-bar chorus, often called "playing one".
- **Density during solos** rises and falls with the soloist's energy — comping instruments thin out, then layer back in for chorus highs.
