# Desktop AI coding competitive feature matrix

Research date: 2026-07-26

Scope: production desktop coding-agent experiences from OpenAI Codex, Anthropic Claude Code for Desktop, Cursor, and the most likely intended “Zcode.” Only first-party product documentation, changelogs, security pages, and official repositories are used. A feature is marked `Limited` when the first-party source documents a narrower implementation, and `Not evidenced` when this review found no first-party proof; the latter is not proof that a feature cannot exist.

## “Zcode” identification

The name is ambiguous:

- **Z.ai ZCode** is the most likely intended comparator because its official documentation calls it an Agentic Development Environment for planning, coding, reviewing, terminal work, long-running goals, and multi-agent collaboration. It is the product used in the matrix below. [Z.ai ZCode overview](https://zcode.z.ai/en/docs/welcome)
- An unrelated **Zcode** at `zcodeapp.com` is a beta macOS tool for building Apple-platform apps. Its own site says it has no code editor and is meant to sit beside VS Code, Cursor, Vim, or another IDE. It is not used as the parity target. [Zcode for Apple platforms](https://zcodeapp.com/)

## Prioritized parity implications for Codinal

These are parity requirements derived from the matrix, not claims about Codinal’s current implementation. Each must be checked against product evidence before being treated as a gap.

1. **P0 — Trust and recovery floor:** scoped OS-enforced filesystem/network sandboxing, inspectable approval rules, secure credentials, reliable signed updates, selective diff review, and automatic checkpoints that can restore Agent code, conversation, or both without touching manual edits.
2. **P0 — Daily coding floor:** integrated terminal takeover, project file tree, fast symbol/text/semantic search, explicit `@file`/folder/Git/past-session context, multi-root repositories, durable searchable/forkable sessions, and first-class model/provider switching.
3. **P1 — Parallel delivery:** isolated worktrees, async/background subagents, dependency-aware plan-to-build, best-of-N or judged alternatives, clear task status/notifications, and safe foreground adoption of a worker branch.
4. **P1 — Ship loop:** native Git branch/commit/status, PR creation and review, CI monitoring with opt-in auto-fix, local/SSH/cloud handoff, and mobile or external approval/steering for long-running work.
5. **P1 — Ecosystem and governance:** MCP plus plugin/skill/hook lifecycle, source/scope/permission visibility, enterprise allowlists and managed policy, SSO/SCIM, audit/analytics APIs, retention/ZDR controls, and model/provider governance.

Later differentiation should include browser preview and visual annotation, image/PDF/log artifacts, scheduled automations, voice/mobile control, and signed macOS/Windows/Linux distribution. Cursor remains the strongest editor-centric benchmark because it combines code intelligence and inline completion with the agent stack; Claude Desktop and Codex are stronger command-center benchmarks; Z.ai ZCode is a useful benchmark for model-agnostic providers, persistent goals, generated repo knowledge, and remote/bot control.
